# Free-tips latest-article feed — local implementation, 13 October 2026

The exact `/free-betting-tips` Astro preview can now display a **read-only, fresh staging WPGraphQL** list of the five latest published posts, but only with `MIGRATION_STAGING_FREE_TIPS_FEED_READ=1` at build time. The existing fixture list remains for the standalone design pilot when the flag is absent; the exact page continues to withhold a current feed by default. No WordPress write, live request, deployment, offer activation, or robots change was made.

The adapter in `src/lib/staging-free-tips-feed.mjs` allows only `https://wordpress-159231-2098144.cloudwaysapps.com/graphql`, sends an unauthenticated POST query, and requires five distinct published IDs and exact safe internal URIs. It turns titles into plain text, validates publication dates, and imports **no excerpt, offer copy, affiliate destination, or CTA**. An opted-in HTTP, GraphQL, identity, count, or date failure stops the build rather than silently substituting the dated fixture list. The page labels the section as a staging preview and retains `BaseLayout`'s exact-page `previewOnly`/noindex behavior.

Local verification: `node --test tests/free-tips-editorial.test.mjs` passed 3/3 tests, covering the old editorial extraction plus feed validation, opt-in, staging-host restriction and fail-closed errors. The full `npm run test:content` suite passed 115/115; `npm run check` reported zero errors/warnings/hints across 266 Astro files. No staging WPGraphQL fetch was made in this run; the first opt-in build still needs a healthy staging endpoint and a visual/link QA pass. This is a latest-posts feed, **not** the daily selections/tip-table data model or an approved commercial-offer feed.
